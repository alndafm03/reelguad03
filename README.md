# ReelGuard

أداة شخصية (للاستعمال الخاص، غير مخصصة للنشر على Google Play) تحدّ من مشاهدة المقاطع القصيرة في:
**Instagram Reels** و**Facebook Reels** و**YouTube Shorts**. كل شيء محلي ولا يوجد إذن إنترنت.

## كيف تعمل
تختار أحد **نظامين للحماية** (ويمكن تغييره لاحقًا بقيود، ولا يُبدَّل أبدًا أثناء الإيقاف):
- **حسب عدد الريلز:** تُحتسب المقاطع التي شوهدت ≥ 4 ثوانٍ، برصيد مشترك بين التطبيقات المختارة (1–999).
- **حسب الوقت:** يُحتسب الوقت الذي تقضيه داخل التطبيق كاملًا (الشاشة مضاءة والتطبيق في الواجهة)، بمدة تحددها (1–720 دقيقة). لا يُقرأ محتوى الشاشة في هذا النظام.

**وضعا الحماية** (في النظامين):
- **تنبيه فقط:** تنبيه عند نفاد الرصيد/الوقت دون قفل، ثم تُعاد التعبئة بعد «مدة الإيقاف».
- **رصيد + تقييد فوري:** عند نفاد الوقت يُقفل التطبيق فورًا؛ وفي نظام الريلز تُكمل المقطع الحالي ثم يُقفل عند أي مقطع جديد.

**مدة الإيقاف** حرّة (1–1440 دقيقة). بعد انتهائها تبدأ دورة جديدة برصيد كامل.

لا يوجد إيقاف للحماية ولا إيقاف مؤقت. **التشديد يسري فورًا، والتخفيف مؤجَّل 24 ساعة** (رفع الريلز أو الوقت، تقصير الإيقاف، وضع أخفّ، إزالة تطبيق، تبديل النظام) حتى أثناء القفل. المدة في `PolicySettings.WEAKEN_DELAY_MS`.
القفل يحجب التطبيق المحميّ كله، والصوت قد يستمر تحته.

##التقنيات المستخدمة:
 جدول يوضح Kotlin، Android SDK 34 (minSdk 26)، Gradle 9.6.0 + AGP 9.4.1، AccessibilityService، Overlay، بلا مكتبات خارجية (JUnit فقط)، وCI عبر GitHub Actions.
 
## الكشف
لكل تطبيق ملف في `app/src/main/assets/detection_profile_<app>.json`. المعرّفات فيها **ترشيحات غير مؤكدة** وتتغير بين إصدارات التطبيقات:
عايِر كل تطبيق من شاشة «معايرة الكشف». Facebook هو الأضعف (واجهته بلا معرّفات تقريبًا) ويبدأ بالاعتماد على contentDescription.

## بصمة هوية المحتوى
`حساب + بداية الوصف (80 حرفًا) + عنصر ثالث (مقطع الصوت إن اكتُشف)`. عند تمريرة مستقرة تنتهي بنفس البصمة يُعامل المحتوى كجديد
(بلا منع تكرار) ويُسجَّل اشتباه تصادم في «التشخيص» (`identityCollisionSuspects` ونسبته إلى الانتقالات).

## البناء والاختبار
المتطلبات: Android Studio حديث (JDK 17+)، وAGP 9.4.1 مع Gradle 9.6.0 (يُنزَّل تلقائيًا عبر الـwrapper)، وحزمة Android SDK Platform 34.
```
./gradlew testDebugUnitTest assembleDebug
```
الـAPK: `app/build/outputs/apk/debug/app-debug.apk`. فعّل الخدمة من إعدادات الوصول، وعلى Android 13+ مع APK مثبّت يدويًا اسمح أولًا بـ«الإعدادات المقيّدة» من معلومات التطبيق.
